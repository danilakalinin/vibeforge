A scratchpad that
answers right away

A free, open-source alternative to paid scratchpads such as RunJS: JavaScript, TypeScript and PHP with a built-in AI assistant. Everything runs on your own machine — no browser, no cloud.

🍎 Download for macOS Source code

Apple Silicon · ~7 MB · free

🧩What you get

One window instead of an editor, a terminal and a chat tab.

📝

Monaco editor

The same engine as VS Code: highlighting, folding, completion.

⚡

Live execution

Output streams line by line through your own Node.js and PHP. Auto-run on type is optional.

🤖

The AI sees your code

Claude, OpenAI, Groq, DeepSeek, OpenRouter. Your editor contents and the project's dependencies go into the context automatically.

🔗

Project linking

Point at a folder and the assistant reads its package.json or composer.json. Laravel projects also get facade and class completion.

🎨

13 themes

Two of them use the native macOS window material. They apply instantly.

📚

Snippets and history

A local SQLite store. Run history remembers which project it belonged to.

🎛️Themes and settings

Theme and interface language switch instantly — no Save, no restart.

🪟Real glass, not a filter

The Glass themes use the native macOS vibrancy: the window is genuinely transparent and the system blurs your desktop behind it. That is the system material, not a CSS imitation.
