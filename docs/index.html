VibeForge is a local scratchpad for JavaScript, TypeScript, and PHP — with a built-in AI assistant that sees your code and your project's dependencies.

Download View on GitHub

Everything in one window

⚡

Live execution

Run JavaScript or TypeScript instantly. Output streams line by line as the process runs — no page reload, no browser tab.

🤖

AI chat with context

Ask Claude, GPT-4o, Groq, DeepSeek, or OpenRouter about your code. The AI sees your editor content and your project's installed packages automatically.

🎨

Monaco editor

The same editor that powers VS Code — with full syntax highlighting for JS, TS, PHP, and dozens of other languages.

📦

npm built in

Install and remove npm packages without leaving the app. Packages are available immediately in your next run.

🔗

Project linking

Link any local project folder. The AI reads package.json or composer.json and gives context-aware answers for Node and PHP/Laravel projects.

📋

Snippets & history

Save reusable code snippets and browse your execution history. Jump back to any previous run in one click.

macOS only for now. Windows and Linux builds require building on each platform. They'll be added to the same release when available.

macOS note: The app is currently unsigned. After dragging to /Applications, run once in Terminal:
xattr -cr /Applications/VibeForge.app

To uninstall: open VibeForge and pick Help → Uninstall VibeForge… — the app will close and remove all its data automatically.
