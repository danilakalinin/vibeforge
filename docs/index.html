Границы продукта

Это не IDE — и не пытается ей быть

VibeForge — блокнот для кода, который пишут не чтобы выкатить, а чтобы получить ответ: сработает ли этот код, что вернёт этот API, как перебрать этот массив.

01

Нужен отладчик, дерево файлов или сборка?

Берите полноценную IDE — этим VibeForge сознательно не занимается.

02

Держите под рукой файл scratch.js?

Цикл «правка → node scratch.js в терминале» заменяется одним окном.

03

Не любите оставлять код в веб-сервисах?

Всё локально: сниппеты в SQLite, ключи — в ~/.vibeforge/settings.json.

Тёмная и светлая
